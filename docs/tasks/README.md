# Registro de Tareas — Inventory Industry

Este directorio contiene el registro detallado de todas las tareas realizadas en el proyecto, documentando el proceso de desarrollo de principio a fin.

## Estructura

| Archivo | Contenido |
|---------|-----------|
| `00-proyecto-general.md` | Descripción general del proyecto y objetivos |
| `01-seed-data.md` | Documentación de la carga de datos semilla realistas |
| `02-pantallas-ui.md` | Estado de las pantallas y componentes de UI |
| `03-mejoras-pendientes.md` | Lista de mejoras y features futuras |

## Convención

Cada archivo de tarea incluye:
- **Estado**: completado / en progreso / pendiente
- **Fecha**: fecha de realización
- **Descripción**: qué se hizo y por qué
- **Archivos afectados**: rutas de archivos modificados o creados
